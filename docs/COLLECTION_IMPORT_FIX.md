# 收藏导入修复与验证记录

日期：2026-09-06

## 问题与修复

- 小红书页面的 `__INITIAL_STATE__` 包含 JavaScript `undefined`，旧版直接 `JSON.parse` 会失败。新增安全数据读取器，识别字符串边界、替换非字符串的 `undefined`，不执行页面脚本。
- 抖音 URL 编码的 `RENDER_DATA` 在解码前被要求包含大括号，导致漏解析；原逻辑还只检查第一个 loader 节点。现在支持编码数据和嵌套帖子数据，并在没有实际媒体时提示解析失败。
- 外部服务优先、重复导入再次解析、等待在线标签模型叠加了延迟。现在直接读取平台页面，抖音静态数据不足时由应用自身的隔离浏览器加载分享页；一次解析结果直接保存，导入使用本地标签提取，在线重新打标功能保留。
- 已按要求删除外部解析服务、XHS-Downloader 托管引擎、安装/启停逻辑、诊断功能、IPC 接口和设置入口。
- 媒体改为流式下载，图片并发 4 路，视频与图片同时下载。单图上限 30 MB / 25 秒，视频上限 300 MB / 120 秒；IPC 导入、重抓共用 180 秒取消信号。文件校验后才使用正式文件名，下载失败清理临时文件。
- 卡片保留标题、摘要和本地缩略图；详情读取数据库正文、本地图片和视频。视频没有封面时用本地 FFmpeg 抽帧；补齐生产页面视频 CSP、媒体协议 Range 请求头和 FFmpeg 打包配置。
- 导入显示解析、下载数量、保存阶段。媒体失败会提示并记录到详情，重抓失败保留原有本地媒体；同一帖子按平台和作品 ID 去重。
- 详情加载失败、内容被删除时显示错误，避免一直“载入中”；详情重新抓取后同步刷新卡片。
